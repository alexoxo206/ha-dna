# HA DNA

Voguing overlay for any song. Crash, hats, and HA sit on top of the record.

The session opens on an original 129 BPM F-minor bed in the pocket of *karma is*. Drop your own audio file to remix the master. Loading a song switches to **Ha Layer** — hats and the dip cue, without a second kick.

## Run

```bash
npm install
npm run dev
```

Open the app, hit Play, then try the pads (`1–4`, `QWER`, `ASDF`). Patterns: Classic Ha, Ha Layer, Fem Dip, Allure. Record writes a mix you can download.
